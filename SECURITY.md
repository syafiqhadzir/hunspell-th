# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We accept vulnerability reports via email.

**Do not report security vulnerabilities through public GitHub issues.**

Please email **syafiqhadzir@live.com.my** with a description of the vulnerability. We will acknowledge your email within 48 hours.
